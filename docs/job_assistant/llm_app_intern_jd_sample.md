# 大模型应用开发实习生岗位样例

## 岗位职责

- 参与基于大语言模型的应用系统开发，包括 Agent、RAG、工具调用与多轮对话能力。
- 参与 Prompt 设计、知识库构建、检索优化与结果评估。
- 参与前后端联调，支持流式输出、会话管理和可视化交互。
- 参与系统部署、调试和线上问题排查，提升稳定性与用户体验。

## 任职要求

- 熟悉 Python，了解 FastAPI、LangChain 或 LangGraph 中至少一项。
- 了解向量检索、Embedding、RAG、ReAct 或 Tool Calling 等大模型应用模式。
- 具备基本的前端协作能力，能够理解 API、SSE、状态管理等应用开发问题。
- 具备良好的问题拆解能力，能快速定位并修复工程问题。

## 加分项

- 有开源项目二次开发经验。
- 有知识库问答、简历优化、面试助手等垂直场景项目经验。
- 熟悉 Docker、MySQL、Redis、Elasticsearch、Milvus/Chroma。
